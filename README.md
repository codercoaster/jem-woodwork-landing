# Jem Woodwork landing

Static mockup of a landing page for Jem Woodwork, a family carpentry business in Brooklyn, NY.

Built with plain HTML, CSS and GSAP. There is no build step.

## Run it

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Before going live

- Replace the stock photos in `assets/img/work-*`, keeping the file names.
- Delete the `noindex` line in `index.html` to allow search indexing.
- If the site moves to its own domain, update the URLs in `index.html`, `robots.txt` and `sitemap.xml`.
